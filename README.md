# AtliQ Grands Hospitality Power BI Dashboard

An interactive Power BI dashboard for analyzing hotel bookings, room performance, occupancy, revenue, and customer booking trends for AtliQ Grands.

## Project Overview

This project turns hotel booking data into business-ready insights for hospitality decision-making. The dashboard helps users compare properties, monitor room categories, evaluate booking channels, and identify changes in revenue and occupancy over time.

## Included Files

- `AtliQ_Grands_Hospitality_Dashboard_PowerBI.pbix` - Power BI report and dashboard.
- `dim_date.csv` - Date dimension used for time-based analysis.
- `dim_hotels.csv` - Hotel and property reference data.
- `dim_rooms.csv` - Room category reference data.
- `fact_aggregated_bookings.csv` - Aggregated booking and occupancy metrics.
- `fact_bookings.csv` - Booking-level records for detailed analysis.

## Key Analysis Areas

- Revenue and booking performance
- Occupancy and room utilization
- Hotel and property comparisons
- Room category performance
- Booking platform and channel trends
- Time-based performance analysis

## How to Use

1. Download or clone this repository.
2. Open `AtliQ_Grands_Hospitality_Dashboard_PowerBI.pbix` in Power BI Desktop.
3. If Power BI prompts for data-source paths, reconnect the queries to the CSV files in this repository.
4. Refresh the data and use the report filters to explore the results.
